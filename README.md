# Simple Machine Learning Text Classifier

This Python script demonstrates a fundamental concept in Artificial Intelligence: text classification. It trains a simple machine learning model to distinguish between 'spam' and 'not_spam' emails based on a small dataset, showcasing how AI can learn from data to make predictions.

## Language

`python`

## How to Run

1. Ensure you have Python installed.
2. Install the scikit-learn library: pip install scikit-learn
3. Run the script: python main.py
